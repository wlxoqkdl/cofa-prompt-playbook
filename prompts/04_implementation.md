# 04 승인 단위 구현

`RULES.md`를 적용한다. 시험 루트 README, 확정 계획, 상태 문서가 있으면 해당 문서를 읽어 줘.

1. 현재 작업 ID, 완료 기준, 승인받은 경로와 명령을 확인해 줘. 승인이 없거나 범위가 불분명하면 필요한 승인만 요청하고 멈춰 줘.
2. 기존 파일과 사용자 변경을 보존하면서 승인한 단위만 구현해 줘. 기존 구현과 테스트를 활용하고 다른 기능이나 문서의 변경이 필요하면 근거를 제시하고 승인받아 줘.
3. 승인 범위의 테스트나 수동 검증을 수행하고 변경 파일, 확인한 결과, 미검증 사항을 구분해 보고해 줘. 실패하면 가능한 재현 절차를 알려 줘.
4. 상태 문서 갱신도 승인된 경우에만 수행해 줘. 다음 단위는 승인 범위를 확인한 후 시작해 줘.
