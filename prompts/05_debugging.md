# 05 디버깅

**권장 모델 및 추론 수준** · Sol 6.1 / 단순 재현은 Medium, 여러 구성 요소가 얽힌 문제는 High. High로도 필수 기능이 막히면 남은 시간과 재현 근거를 확인한 뒤 XHigh를 고려한다.

`RULES.md`를 적용한다. 기대 동작, 실제 동작, 재현 입력, 관련 명령과 오류 위치를 확인해 줘. 로그와 데이터는 시험 환경 내부에서만 사용해 줘.

1. 승인된 명령 범위에서 가장 짧은 재현 절차를 실행해 줘. 실행할 수 없다면 이미 확보한 로그로 분석하고 재현 여부를 명시해 줘.
2. 최근 변경과 관련 경로를 좁혀 가설, 가설을 뒷받침하거나 배제하는 증거, 가장 가능성 높은 원인을 구분해 줘.
3. 최소 수정 범위와 재검증 방법을 제시해 줘. 범위가 이미 승인됐는지 확인하고, 추가 변경은 승인받아 줘.
4. 수정 후 같은 입력으로 재현 여부와 인접 기능의 회귀를 확인해 줘.
