# 07 세션 인계와 제출 직전 정리

`RULES.md`를 적용한다. 현재 파일 상태와 마지막 검증 결과를 확인해 줘. 새 세션에 필요한 현재 목표, 승인 범위, 완료 근거, 미해결 사항, 서버·테스트 실행 방법과 다음 한 가지를 정리해 줘. 상태 문서 갱신이 승인됐다면 1번 터미널에서 그 문서만 갱신해 줘.

새 세션에는 아래 지시를 전달한다.

```text
시험 루트 README.md, cofa-prompt-playbook/RULES.md와 현재 PROJECT_STATUS.md가 있으면 읽어 줘. 승인 범위, 실제 변경과 검증 상태, 다음 작업을 먼저 보고해 줘. 파일 변경과 외부 전송 없이 여기서 멈춰 줘.
```

제출 전에는 공식 제출 대상과 저장 여부를 확인하고, 검증하지 못한 항목을 그대로 기록한다. 응시자가 Cofa의 공식 제출 화면에서 파일 확정과 후속 서술형을 진행하고 최종 완료 화면을 확인한다. 후속 서술형에서는 AI를 사용하거나 답안을 복사·붙여넣지 않는다. 시험 작업과 상태 기록은 시험 환경 안에 둔다.
