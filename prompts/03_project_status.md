# 03 프로젝트 상태 문서

**권장 모델 및 추론 수준** · Sol 6.1 / Medium

`RULES.md`를 적용한다. 확정 계획과 승인 경로를 확인해 줘. 과제가 상태 문서를 허용하고 응시자가 생성 또는 편집을 승인했을 때만 시험 환경의 `PROJECT_STATUS.md`를 작성해 줘. 공식 문서 형식이 지정됐다면 그 형식을 우선해 줘. 기존 상태 문서가 있으면 먼저 읽고 사실과 결정의 변경 이력을 보존하며 필요한 항목만 갱신해 줘.

```markdown
# 프로젝트 상태
- 현재 작업과 다음 한 가지
- 요구사항 ID와 근거 위치
- 업무 담당자 맥락 및 확인되지 않은 가정
- 결정, 선택 이유, 적용 범위
- 작업별 상태 [대기 / 진행 / 검증 완료 / 보류]
- 승인된 경로·명령과 실제 변경 파일
- 검증 명령과 실제 결과 [통과 / 실패 / 미실행]
- 남은 결함·위험 및 제출 점검
```

구현 단위 완료, 중요한 결정 변경, 재검증, 세션 인계 시 갱신한다. 1번 터미널을 작성 담당으로 둔다. 시험 루트 README에 기록하지 않으며 실제 상태 문서를 공개 플레이북에 복사하지 않는다. 문서를 생성할 수 없다면 같은 구조로 Cofa 내부 세션에 요약해 줘.
