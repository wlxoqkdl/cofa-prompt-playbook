# 01 탐색과 업무 담당자 인터뷰

## Codex에 전달

`RULES.md`를 적용한다. 시험 루트의 `README.md`와 과제 안내를 읽고 필요한 디렉터리, 진입점, 기존 테스트와 실행 방법을 조사해 줘. Git이 있으면 `git status --short`와 README의 기존 변경 여부를 확인해 줘. 파일 생성·편집·삭제, 설치, 네트워크 요청 없이 진행해 줘.

- 필수 기능, 제약, 제출 파일과 형식, 우선 확인할 사용자 흐름을 근거 위치와 함께 정리해 줘.
- 기존에 동작하는 부분, 확인이 필요한 부분, 원본 보호 대상을 구분해 줘.
- 공식 문서로 확정된 내용, 추정, 업무 담당자에게 질문할 사항을 분리해 줘. 답변을 기다리고 멈춰 줘.

## Cofa 내 업무 담당자에게 직접 전달

시험에서 해당 기능을 제공할 때 Cofa의 **업무 담당자** 메신저에서 질문한다. 화면 조작이나 제출 절차는 Cofa Helper에 묻는다.

```text
이 업무를 주로 하는 사람과 가장 자주 겪는 불편을 알려 주세요. 지금은 어떤 순서로 처리하며, 최근에 반복된 문제를 일반적인 사례로 설명해 주실 수 있나요? 이 문제를 해결했다고 판단할 수 있는 최소 기준은 무엇인가요?
```

답변을 바탕으로 예외 입력, 현장 제약, 우선순위 중 실제 구현에 영향을 줄 두세 가지를 추가로 확인한다. 필요하면 계획에서 가장 중요한 사용자 흐름 하나를 짧게 확인한다. 응시자가 Cofa 내부에서만 요약을 02의 입력으로 제공한다. 공식 요구사항과 충돌하는 답변은 따로 표시하고 추측으로 요구사항을 바꾸지 않는다.
